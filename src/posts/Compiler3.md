# 一、从非形式描述的语言到正则表达式

## 1. 自然语言 → 正则表达式

关键是把自然语言拆解成几个条件

例如：

* “由 0 和 1 组成”：每个字符可以是 0 或 1，对应 $0|1$
* “前面可以出现任意多个字符”：对应闭包 $(0|1)^*$
* “以 1 结尾”：最后必须连接一个 1

因此，正则表达式为：

$$
(0|1)^*1
$$

这里的运算符号含义是：

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| $a\|b$ | 选择，表示 $a$ 或 $b$ | $0\|1$ |
| $ab$ | 连接 | 01 |
| $a^*$ | 闭包，表示重复零次或多次 | $0^*$ |
| $\varepsilon$ | 空串 | 长度为 0 的字符串 |
| $\varnothing$ | 空语言 | 不包含任何字符串 |

注意：$\varepsilon$ 和 $\varnothing$ 完全不同。前者表示一个字符串，后者表示一个空集合

```fold 更多例子
| 自然语言描述 | 正则表达式 |
| --- | --- |
| 所有以 0 开头的二进制串 | $0(0\|1)^*$ |
| 所有包含子串 01 的二进制串 | $(0\|1)^*01(0\|1)^*$ |
| 所有只由 1 构成的字符串，允许空串 | $1^*$ |
| 所有长度恰好为 2 的二进制串 | $(0\|1)(0\|1)$ |
| 所有以 01 结尾的二进制串 | $(0\|1)^*01$ |
```

## 2. 正则表达式 → 自然语言

从正则表达式中识别三个核心运算：

* 并运算 `|`：满足其中一个分支。
* 连接：先满足左边，再满足右边。
* 闭包 `*`：对应的模式可以重复任意次，包括零次。

例如：

$$
(0|1)^*01
$$

表示任意多个二进制字符后面接上 `01`，也就是“所有以 01 结尾的二进制串”。

**考试技巧：** 先分析最后一个字符或固定子串，再分析前后可以任意出现的部分，通常更容易写出正确表达式。

# 三、从 NFA 到 DFA

定义：
$\varepsilon$-闭包($\varepsilon-closure$) ：状态s 的 $\varepsilon$-闭包是 s 经 $\varepsilon$ 转换所能到达的状态集合

方法：**子集构造法**

NFA 的初始状态的 $\varepsilon$-闭包对应于 DFA 的初始状态

针对每个 DFA 状态 – NFA 状态子集 $A$，求输入每个 $a_i$ 后能到达的 NFA 状态的 $\varepsilon$-闭包并集 $\varepsilon\text{-} closure(move(A, a_i))$

该集合对应于 DFA 中的一个已有状态，或者是一个要新加的 DFA 状态

> 子集构造法得到的 DFA 不一定为最简

# 四、DFA 的化简

**核心思想**：将状态划分为不相交的子集，同一子集内的状态不可区分

1. **初始划分**：将状态分为两组：**接受状态组** 和 **非接受状态组**
2. **迭代分解**：检查每个组，如果组内的状态在输入同一个字符后，跳转到了不同的组，则将它们拆分。重复直到不能再拆
3. **合并**：从每个子集中取一个代表，画出最简DFA
